# RhythmFace

> **Archived 2D lip-sync prototype. This repository is not maintained or supported.**

RhythmFace explored microphone feature extraction, rule-based mouth-shape selection, and Pygame rendering for a generated 2D character.

## Archive status

- The package, documentation build, microphone path, and five test files were not revalidated against current Python or dependency versions during archival.
- Earlier claims about test counts, complete implementation, documentation hosting, and real-time vowel detection were removed because they were stale or not supported by current evidence.
- The asset generator creates neutral demonstration graphics; no character-art quality or production lip-sync accuracy is claimed.
- No package has been confirmed on PyPI and no release artifacts exist in this repository.

The source remains available for historical inspection. There is no designated maintained successor; current public work is listed in the [open-source portfolio](https://www.mehmeterendereli.com/en/open-source).
